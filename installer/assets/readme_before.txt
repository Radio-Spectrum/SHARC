SHARC - Spectrum sharing and compatibility simulator

This setup installs the SHARC desktop application (Monte Carlo simulation
engine and graphical interface) for 64-bit Windows.

Before you continue:
  - Close any running SHARC window.
  - Campaign files, logs and simulation results are stored in your own
    Documents\SHARC folder, never inside the program folder.
  - The 3D preview downloads map imagery online; an internet connection is
    needed for that feature only.
